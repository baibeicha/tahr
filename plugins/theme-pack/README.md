# Community Themes Pack (`theme-pack`)

A collection of popular developer themes crafted for Tahr IDE.

## Included Themes
- **One Dark Pro**: The iconic Atom/VS Code color palette.
- **Rosé Pine**: Soothing minimalist palette with warm pine and muted rose accents.
- **Kanagawa Wave**: Traditional Japanese color palette inspired by Katsushika Hokusai.
- **Cyberpunk Neon**: High-contrast vibrant retro-futuristic theme.

## Activation
Use `:colorscheme <theme-name>` or select from the Settings / Theme picker palette.
