# TypeScript & JavaScript Support for Tahr IDE (`tahr-ts`)

Language extension providing first-class modern TypeScript and JavaScript development in Tahr IDE.

## Features
- **Language Server (LSP)**: Powered by `typescript-language-server` with JSDoc support, module auto-imports, refactorings, and type checking.
- **Runtime Autodetection**: Automatically discovers Node.js, Bun, and Deno runtimes.
- **Debugging**: Chrome/Node V8 inspector integration for breakpoints and console evaluation.
- **Scaffolding**: Quickstart templates for Vite + React/Vue and Node/Bun server apps.
