# Developer Utility Suite (`devtools`)

Built-in offline utilities for everyday developer tasks without leaving Tahr IDE.

## Features
- **Utilities Palette (`Ctrl+Shift+U`)**: Fast modal access to common transformation tools:
  - **JWT Decoder**: Inspects header and payload claims, checks `exp` expiry date.
  - **Unix Timestamp**: Converts epoch seconds/milliseconds to UTC and local human-readable datetime, and vice versa.
  - **UUID Generator**: Generates RFC 4122 UUID v4 with 1-click clipboard copy or buffer insert.
  - **Base64 / URL**: Encode and decode standard, URL-safe, and Hex strings.
  - **Cryptographic Hashes**: Compute SHA256, SHA512, MD5, and HMAC signatures of input text or buffer selection.
  - **JSON Prettifier & Minifier**: Instant format and compacting of raw JSON strings.
- **Privacy First**: 100% offline, zero external HTTP telemetry or data leakage.
