# Git Worktree Manager (`git-worktree`)

First-class Git worktree management directly inside Tahr IDE.

## Features
- **Instant Parallel Workspaces**: Work on multiple Git branches simultaneously in separate directories without stash juggling or rebuild overhead.
- **List & Switch**: Press `Ctrl+Alt+W` to open the Worktree Picker, viewing active branches, paths, and HEAD commits. Switch workspace root in 1 click.
- **Add & Remove**: Interactively scaffold a new worktree linked to a new or existing branch.
