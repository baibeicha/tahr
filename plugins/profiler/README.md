# Performance Profiler & Flamegraphs (`profiler`)

Integrated profiling suite with interactive flamegraph rendering for Go and native binaries.

## Features
- **Interactive Flamegraph**: Zoom, pan, and search through stack frames rendered directly inside Tahr IDE.
- **Support for Standard Formats**: Open `.pprof` and `.prof` files generated by Go, Rust, or C/C++ profilers.
- **Live Endpoint Capture**: Connect to `http://localhost:6060/debug/pprof` to pull CPU, heap, goroutine, or block profiles on demand.
- **Top Hotspots Table**: View flat and cumulative CPU/memory consumption with jump-to-code navigation.
- **Zero-CGO Pure Go Parser**: Uses standard protobuf-based pprof format parsing without external graphviz or perl dependencies.
