# Visual Git Graph (`git-graph`)

Interactive commit graph and repository visualizer for Tahr IDE.

## Features
- **Visual Graph Rendering**: Displays branch topologies, branch forks, merges, and commit nodes cleanly in both TUI (box-drawing characters) and GUI (vector curves).
- **Commit Details**: Click on any commit in the graph to view author, date, full commit message, and changed files with diffs.
- **Branch & Tag Badges**: Clear visual badges for active branch, remote tracking branches, and tags.
- **Keybinding**: Press `Ctrl+Shift+G` or click `[Git]` in the bottom panel drawer.
