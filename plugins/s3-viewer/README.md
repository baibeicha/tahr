# S3 Object Storage Explorer (`s3-viewer`)

Fast S3-compatible cloud and on-premise object storage browser.

## Features
- **Multi-Provider Support**: Compatible with Amazon S3, MinIO, Cloudflare R2, Google Cloud Storage, and Ceph.
- **Bucket & Prefix Tree**: Fast virtualized hierarchy explorer for buckets with millions of objects.
- **Quick Object Preview**: View text, markdown, JSON, and image files directly inside the editor without downloading locally.
- **Multipart Upload & Download**: High-throughput file transfers with progress notifications.
- **Pure-Go Signature V4**: Pure Go implementation of AWS SigV4 signing over HTTPS without heavy external SDK dependencies.
