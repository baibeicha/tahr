# Git Lens: Inline Blame & Diff (`git-lens`)

Seamless Git intelligence built right into the editor viewport.

## Features
- **Inline Blame Virtual Text**: Shows author, commit date, and commit message at the end of the active line.
- **Gutter Diff Indicators**: Visual color-coded bars indicating added, modified, or deleted line blocks relative to HEAD.
- **Side-by-Side Diff View**: Interactive visual diff panel comparing working copy against index or specific commit.
