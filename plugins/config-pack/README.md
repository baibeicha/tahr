# Config Formats: JSON, YAML & TOML (`config-pack`)

Essential configuration format tooling for modern software projects in Tahr IDE.

## Features
- **Tree-sitter Syntax Highlighting**: Accurate, incremental syntax coloring for `.json`, `.yaml`, `.yml`, and `.toml`.
- **JSON Schema Validation**: SchemaStore integration for `package.json`, `tsconfig.json`, GitHub Actions, Kubernetes manifests, and Docker Compose.
- **Document Structure**: Symbol outline and folding for nested configuration keys and sections.
