# Side-by-Side Diff Viewer (`diff-tool`)

Visual difference comparison tool powered by Tahr's Myers Diff Engine.

## Features
- **Arbitrary File Comparison**: Compare any two files in your workspace (e.g. `config.prod.yaml` vs `config.dev.yaml`) or active document against clipboard content.
- **Synchronized Viewport Scrolling**: Both panes scroll together with aligned line numbers and visual connection spans.
- **Intra-line Word/Char Highlighting**: Shows exact character deletions, insertions, and replacements within modified lines.
- **Shortcuts**:
  - `Ctrl+Shift+D`: Compare active file with another selected file.
  - `Ctrl+Alt+D`: Compare active buffer with clipboard contents.
