# Rust Language Support for Tahr IDE (`tahr-rust`)

Official Rust language extension for high-performance systems development in Tahr IDE.

## Features
- **Language Server (LSP)**: Powered by `rust-analyzer` with type annotations, inlay hints, completion, macro expansion, and lifetime/borrow diagnostics.
- **Cargo Integration**: Seamless execution of `cargo build`, `cargo check`, `cargo test`, and `cargo clippy`.
- **Debugging (DAP)**: Debugging via `lldb-dap` or `codelldb` with native memory and thread inspection.
- **Project Templates**: Scaffolding for Cargo binary applications and Cargo libraries.
