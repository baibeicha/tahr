# Python Language Support for Tahr IDE (`tahr-python`)

Official Python language extension for scientific computing, backend APIs, and scripting in Tahr IDE.

## Features
- **Language Server (LSP)**: Powered by Microsoft `pyright` for fast static typing, parameter hints, auto-imports, and navigation.
- **Debugging (DAP)**: Interactive debugging via `debugpy`.
- **Virtualenv Autodetection**: Automatically locates `.venv`, `venv`, Conda, and Poetry virtual environments.
- **Testing**: Native discovery and execution of `pytest` and `unittest` suites.
