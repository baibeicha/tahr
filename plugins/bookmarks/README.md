# Code Bookmarks & Navigation (`bookmarks`)

Quickly mark lines across your codebase and navigate between them effortlessly in Tahr IDE.

## Features
- **Toggle Bookmark**: Press `Ctrl+F2` to toggle a bookmark on the active line.
- **Cycle Bookmarks**: Press `F2` for next bookmark and `Shift+F2` for previous bookmark.
- **Bookmark Picker**: Press `Ctrl+Shift+B` to open an interactive fuzzy-search list of all bookmarks in the project.
- **Gutter Indicators**: Distinctive visual glyph displayed directly in the editor line gutter.
