# C & C++ Language Support for Tahr IDE (`tahr-clangd`)

Official C and C++ language extension providing enterprise-grade developer tooling for native projects.

## Features
- **Language Server (LSP)**: Powered by LLVM `clangd` with semantic highlighting, header inclusion hints, AST-accurate code completion, and compile commands integration.
- **Build System Integration**: Automatically discovers `compile_commands.json` generated by CMake, Meson, Bear, or Makefiles.
- **Debugging (DAP)**: High-performance native debugging via `lldb-dap` or `gdb`.
