# Markdown Live Preview (`markdown-preview`)

Split-pane live Markdown previewer for documentation, readmes, and notes in Tahr IDE.

## Features
- **Live Side-by-Side Preview**: Real-time rendering synchronized with the editor buffer scroll position.
- **Rich Elements**: Renders GitHub Flavored Markdown (GFM) tables, task lists `[x]`, blockquotes, and alerts.
- **Fenced Code Blocks**: Syntax highlighting inside fenced code blocks matching the editor color theme.
