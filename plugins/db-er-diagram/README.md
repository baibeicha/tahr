# Database ER Diagram & Schema Designer (`db-er-diagram`)

Interactive 2D entity-relationship (ER) diagram visualizer, schema modeler, and architecture designer for Tahr IDE.

## Features
- **2D DAG Canvas**: Interactive pan/zoom 2D canvas with Sugiyama multi-layer auto-layout.
- **Crow's Foot Notation**: Visualizes Primary Key (PK) to Foreign Key (FK) cardinality relations.
- **Hybrid Schema Discovery**: Automatically syncs with live database connections (`db-inspector`) or parses local `.sql` / migration files.
- **Table Search & Filter**: Instant search to highlight tables and connected relations.
- **Multi-Format Export**: Export architecture diagrams directly to Mermaid ER format or DDL migration files.
